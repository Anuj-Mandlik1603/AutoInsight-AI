### Q2: Explain your AI integration in detail
**Perfect Answer**:
"We use Google Gemini Pro API in four steps:

**Step 1 - Data Extraction**: We process the uploaded data and extract key metrics like total revenue, growth rates, anomalies, and correlations.

**Step 2 - Prompt Engineering**: We create a structured prompt that includes:
- Dataset summary (rows, columns, metrics)
- Statistical findings (mean, median, trends)
- Business context (industry, KPIs)
- Specific instructions for insight format

**Step 3 - API Call**: Send the prompt to Gemini API and receive natural language response.

**Step 4 - Parsing**: Parse the AI response into sections - executive summary, findings, recommendations, and risks.

The key innovation is grounding the AI in actual data so it doesn't hallucinate. We provide specific numbers in the prompt and request data-backed insights."

### Q3: What algorithms do you use for anomaly detection?
**Perfect Answer**:
"We use the Interquartile Range (IQR) method, a statistical technique:

1. Calculate Q1 (25th percentile) and Q3 (75th percentile)
2. Find IQR = Q3 - Q1
3. Set bounds: Lower = Q1 - 1.5×IQR, Upper = Q3 + 1.5×IQR
4. Any value outside these bounds is flagged as an anomaly

We chose IQR because:
- It's robust to outliers
- Works well with skewed distributions
- Industry standard for business analytics
- Easy to explain to non-technical users

For time-series data, we also use standard deviation methods to detect trend breaks."

### Q4: How do you ensure AI doesn't hallucinate?
**Perfect Answer**:
"We implement three safeguards:

**1. Grounded Prompts**: We provide specific numerical data in the prompt. Instead of 'analyze sales', we say 'Revenue is $45,230, up 15% from last quarter'.

**2. Structured Output**: We request specific format - executive summary, findings, recommendations. This constrains the AI to follow patterns.

**3. Transparency**: We label all insights as 'AI-Generated' and show source data alongside AI text. Users can verify claims.

Additionally, we validate responses programmatically and reject outputs that don't match expected structure."

### Q8: Show me the code - explain the data processor
**Perfect Answer**:
"Let me walk through the key component - data_processor.py:

```python
class DataProcessor:
    def process(self):
        self.clean_data()      # Handle missing values
        detect_column_types()  # Numeric vs categorical
        calculate_statistics() # Mean, median, etc.
        detect_kpis()         # Auto-find revenue metrics
        analyze_trends()      # Growth calculations
        detect_anomalies()    # IQR method
```

**Clean Data**: We handle missing values by filling numerics with median (robust to outliers) and categoricals with mode.

**Detect KPIs**: We scan column names for keywords like 'revenue', 'sales', 'profit' and validate they're numeric.

**Analyze Trends**: For date columns, we sort chronologically and use np.polyfit to calculate trend slope.

The architecture is modular - each method has a single responsibility, making it easy to test and extend."
