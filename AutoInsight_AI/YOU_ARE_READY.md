## ⚡ QUICK TROUBLESHOOTING

### Issue: Can't see "API Key configured"
**Fix**: 
1. Refresh browser (Ctrl + R)
2. OR restart Streamlit:
   - Press Ctrl + C in terminal
   - Run: `streamlit run app.py`
   - Refresh browser

### Issue: Upload button not working
**Fix**: 
- Make sure file path is correct
- File should be in same folder as app.py
- Try drag-and-drop instead of browse

### Issue: "Generate Report" button disabled
**Fix**: 
- Ensure API key shows as configured
- Make sure data is uploaded (preview should be visible)

### Issue: Error when generating insights
**Fix**: 
- Check internet connection (AI needs internet)
- API key might be invalid - refresh page
- Wait a bit longer (can take 20 seconds)

### Issue: No charts showing
**Fix**: 
- Scroll down - they're below the insights
- Wait for analysis to fully complete
- Check for error messages
