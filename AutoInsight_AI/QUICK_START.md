   ```

   ```

5. Click **"Open"**

**OR** just drag and drop `sample_data.csv` into the upload area!

---

### Step 3: Generate Analysis 🤖

1. Scroll down past the data preview
2. Look for **"🔍 Analysis Configuration"**
3. Select **"Sales Analysis"** (it should be default)
4. Keep Insight Depth as **"Detailed"**
5. Click the big purple button: **"🚀 Generate Analysis Report"**

**Wait 10-20 seconds** while the AI analyzes your data...

## ⚡ QUICK ACTIONS

### If the app doesn't refresh:
1. Go to your browser (http://localhost:8501)
2. Press **Ctrl + R** to refresh
3. The API key should now be pre-filled!

### If you see API key errors:
- Check that the key is visible in the sidebar
- It should show "✅ API Key configured"
- If not, the code update might need a restart

### To restart the app:
1. Go to terminal/PowerShell where Streamlit is running
2. Press **Ctrl + C** to stop
3. Run again: `streamlit run app.py`
4. Refresh browser
